# RaGeX Demo Video Plan

## Objective
Create a maximum 3-minute narrated demo video for final submission. It should explain problem, architecture, Exasol role, dashboard workflow, RAG grounding, integration endpoint, and impact.

## Format
- Landscape 16:9
- 1920x1080
- Narrated with burned-in scene text
- Uses real dashboard screenshots from `submission/screenshots/`

## Visual Identity
- Background: `#081222`
- Surface: `#0F1D33`
- Surface 2: `#14263F`
- Border: `#1E3454`
- Text: `#EAF1FA`
- Muted text: `#9CB0CB`
- Cyan: `#35C4F0`
- Violet: `#7C6CFF`
- Green, amber, red only for status/risk

## Storyboard
1. Title and positioning.
2. Problem: pricing bots can move faster than human review.
3. Architecture: Simulator -> Exasol -> Guardrail -> Regret -> RAG -> Dashboard.
4. Main dashboard overview.
5. Decision explorer and filters.
6. Decision detail with evidence.
7. Grounded RAG and refusal behavior.
8. Exasol persistence and vector storage.
9. Integration endpoint handoff.
10. Results and closing.

## Output
- `ragex-demo-3min.mp4`
- `ragex-demo-poster.jpg`
- `narration.txt`
- `captions.srt`
